# Rule engine demo

Interactive demo of a rule engine for a product configurator: click customers and AVs and watch a change travel through the gates.

Three examples (dropdown on the page): AVs for all / 1 / N customers, a customer hierarchy (Top > Account > Org) baked into the model, and a customer picked through an API that returns the parent and grandparent ids.
Open `index.html` (or the GitHub Pages site). Artificial model, generic names, no dependencies.
